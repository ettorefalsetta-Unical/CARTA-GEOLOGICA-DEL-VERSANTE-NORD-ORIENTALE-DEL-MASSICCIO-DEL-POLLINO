# CARTA-GEOLOGICA-DEL-VERSANTE-NORD-ORIENTALE-DEL-MASSICCIO-DEL-POLLINO
Questo repository contiene i dati cartografici digitali e i materiali associati alla CARTA GEOLOGICA DEL VERSANTE NORD-ORIENTALE DEL MASSICCIO DEL POLLINO (CONFINE CALABRO-LUCANO) - scala 1:50.000.

Se utilizzi questo dataset, ti preghiamo di citarlo come di seguito: Falsetta, E. (2025). Carta Geologica del versante nord-orientale del Massiccio del Pollino, scala 1:50.000, in formato vettoriale (Version 1.0) [Data set]. 

Referenza: CARTA GEOLOGICA DEL VERSANTE NORD-ORIENTALE DEL MASSICCIO DEL POLLINO (CONFINE CALABRO-LUCANO). 1995. -  L. TORTORICI, C. MONACO, L. MORTEN, S. CRITELLI, C. TANSI. Scala 1:50000. https://www.pconti.net/egeo_results.php?id=asgb409 

IL DATASET INCLUDE:

Carta Georeferenziata: Versione georeferenziata della carta, pronta per l'uso in software GIS, SR: EPSG:32633 - WGS 84 / UTM zone 33N. (DIMENSIONI ELEVATE - RICHIEDERE ALLA MAIL: ettore.falsetta@unical.it)

Layer Vettorializzati: Layer poligonali e lineari derivati dalla carta, inclusi unità geologiche e caratteristiche strutturali, SR: EPSG:32633 - WGS 84 / UTM zone 33N. in formato Geopackage.

Layer di Stile .qmd: File di layer di stile QGIS per una visualizzazione coerente della carta.

Progetto QGIS: File di progetto QGIS (.qgz) contenente tutti i layer e le impostazioni per un facile accesso e manipolazione dei dati.
